홍콩 환율·구매 계산기 — 사칙연산 수정판
=========================================

구성 파일
- index.html: 웹앱 본체 (환율 계산, 구매 계산, 기록·합계)
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 오프라인 캐시 (v3, 기존 설치판 갱신용)
- icons/: 홈 화면 아이콘

이번 수정 사항
- 키패드를 사용할 때 이전 커서 위치에 입력되는 문제 수정.
- 숫자 키는 항상 계산식 맨 뒤에 입력됩니다.
- 24 + 50 = 74, 10 - 5 = 5, 10 ÷ 4 = 2.5 등 정상 계산됩니다.
- C (초기화), ⌫ (한 글자 삭제), = (결과 확정) 버튼을 배치했습니다.
- = 다음에 숫자를 누르면 새 계산을 시작하고, 연산자를 누르면 직전 결과에 이어 계산합니다.
- 연산자를 연속 입력하면 가장 마지막 연산자로 교체합니다.
- 괄호 버튼을 없애고 간단한 사칙연산 키패드로 정리했습니다.

기존 기능 유지
- 환율 자동 조회 및 수동 입력, 수수료 여유분 조정, 오프라인 환산
- 구매 이름·가격 기록, 전체 총액(HKD/KRW), 기록 수정·삭제·전체 삭제
- 기록 JSON 백업/복원

기록 저장 안내
- 구매 기록은 현재 브라우저에 localStorage로 보관됩니다.
- 동일한 웹주소(같은 브라우저)에 갱신 업로드하면 기존 기록을 계속 사용할 수 있습니다.
- HTML을 새 로컬 파일로 실행하거나 다른 웹주소에서 열면 기존 기록이 보이지 않을 수 있습니다.
  이전 앱에서 '기록 백업'을 내려받고 새 앱에서 '백업 불러오기'를 하세요.
- 브라우저 저장 데이터를 삭제하면 기록이 사라지므로 백업해 두는 것이 좋습니다.

휴대폰 설치 (GitHub Pages 예시)
1. 압축파일 내용을 GitHub의 해당 repository 최상단에 업로드해 기존 파일을 교체합니다.
2. GitHub Settings > Pages > Deploy from a branch > main / (root)를 사용합니다.
3. 웹 주소에 접속 후 Chrome > 홈 화면에 추가/앱 설치를 선택합니다.
4. 기존 앱이 있다면 갱신된 페이지를 새로고침하고 앱을 다시 실행합니다.

환율: Frankfurter API https://api.frankfurter.dev/v2/rate/hkd/krw
실제 카드 청구 금액과 다를 수 있으며 초 단위 실시간 환율은 아닙니다.
